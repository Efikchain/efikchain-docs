What Efikchain is

Efikchain is a production blockchain, not a test network. It runs the same smart contract engine as Ethereum, so most existing tools work without changes.

Works with your wallet

Efikchain is EVM compatible. MetaMask and other EVM wallets connect with the network details on this page.

Smart contracts

Deploy Solidity contracts with the tools you already use, such as Hardhat, Foundry and ethers.

Open and verifiable

The genesis file and node setup are public on GitHub, so anyone can check the chain or run their own node.

Get started in three steps

You only need a wallet that supports custom EVM networks.

  1. Add the network

    Press the button below, or enter the network details manually in your wallet.

  2. Use your address

    Your wallet address is the same on every EVM network. Use it to receive and send EFIK.

  3. Check on the explorer

    Search your address or any transaction hash to see it confirmed on chain.

Build on Efikchain

Point your tools at the public RPC and deploy as you would on any EVM chain.

Check the connection

curl -X POST https://rpc.efikcoin.com \
  -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","method":"eth_chainId","params":[],"id":1}'

# expected result: 0x30c22

Hardhat network config

networks: {
  efikchain: {
    url: "https://rpc.efikcoin.com",
    chainId: 199714,
    accounts: [process.env.DEPLOYER_KEY]
  }
}

Questions

Short answers about the network.

Is this a test network?

No. Efikchain is a mainnet. Transactions on it use real value, so check every address and network detail before you send funds.

What is EFIK?

EFIK is the native coin of Efikchain. It pays transaction fees on the network.

How does the network reach agreement?

Efikchain uses Clique proof-of-authority. Blocks are produced by authorized signers, with a target block time of 5 seconds.

How do I know I am on the right network?

The chain ID must be 199714. The full genesis file is public in the docs repository, so you can compare it with your own node.

Can I run my own node?

Yes. The setup steps and genesis file are in the docs repository on GitHub.
