Developers

Use these settings in your tools. Keep private keys in a local .env file and never commit them.

Hardhat

networks: {
  efikchain: {
    url: "{{rpc}}",
    chainId: {{chainId}},
    accounts: [process.env.DEPLOYER_KEY]
  }
}

ethers.js (v6)

const provider = new ethers.JsonRpcProvider("{{rpc}}", {{chainId}});
console.log(await provider.getBlockNumber());

Foundry

forge create src/MyToken.sol:MyToken --rpc-url {{rpc}} --private-key $DEPLOYER_KEY

Remix

Add the network to your wallet, then in Remix choose Environment: Injected Provider and confirm it shows {{chainId}} before pressing Deploy. In the compiler tab set the EVM version to paris or london.

Quick check

curl -s {{rpc}} -X POST -H "Content-Type: application/json" \
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"eth_chainId\",\"params\":[],\"id\":1}"
