Build on EfikChain

It is EVM-compatible, so Hardhat, Foundry, ethers and MetaMask work as usual.

Hardhat
networks: {
  efikchain: {
    url: "https://rpc.efikcoin.com",
    chainId: 199714,
    accounts: [process.env.KEY]
  }
}
ethers
const p = new ethers.providers
 .JsonRpcProvider(
  "https://rpc.efikcoin.com", 199714);
await p.getBlockNumber();
