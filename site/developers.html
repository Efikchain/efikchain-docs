Build on EfikChain

EfikChain is EVM compatible. Your usual tools work with a different RPC URL and chain ID.

Network nameEfikChain Mainnet
Chain ID199714 (0x30c22)
CurrencyEFIK, 18 decimals
RPChttps://rpc.efikcoin.com
Explorerhttps://explorer.efikcoin.com

Add to a wallet

ethers.js

const provider = new ethers.JsonRpcProvider("https://rpc.efikcoin.com", 199714);
const balance = await provider.getBalance("0xYourAddress");

Hardhat

networks: {
  efikchain: {
    url: "https://rpc.efikcoin.com",
    chainId: 199714,
    accounts: [process.env.PRIVATE_KEY]
  }
}

Foundry

forge create src/MyToken.sol:MyToken \
  --rpc-url https://rpc.efikcoin.com \
  --private-key $PRIVATE_KEY

Keep private keys in environment variables, never in code or in a public repository. The explorer is Blockscout, so contract verification uses the Blockscout API at explorer.efikcoin.com/api/.
