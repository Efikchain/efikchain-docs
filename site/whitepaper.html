1. Abstract

EfikChain is a public, EVM-compatible blockchain. It runs as Mainnet with Chain ID 199714 and the native coin EFIK. Around the chain sit the tools a network needs to be usable: an exchange, a block explorer, a price chart, a wallet and developer documentation. The goal is a complete ecosystem that anyone can use, build on, or fork.

2. Vision

Most new chains ship a node and stop. EfikChain aims to ship the whole stack, so a person can create a wallet, hold value, swap tokens and check every transaction without depending on third-party services. The project is built in the open and is meant to be reusable by other builders.

3. Architecture

  • Execution: EVM compatible, so Solidity contracts and standard tools (Hardhat, Foundry, ethers.js, web3.js, MetaMask) work without changes.
  • Consensus: Clique proof of authority, run on go-ethereum. Approved signers produce blocks.
  • Network access: a public JSON-RPC endpoint at rpc.efikcoin.com, served over HTTPS.
  • Parameters: Chain ID 199714 (0x30c22), native coin EFIK with 18 decimals.

4. Tokens

EFIK is the native coin. It pays transaction fees and moves value on the chain. WEFIK is its wrapped ERC-20 form (1:1), used by contracts that need an ERC-20 token. EUT is an ERC-20 token that trades against WEFIK in the first liquidity pool. All contract addresses are listed on the home page and can be verified on the explorer.

Total supply, distribution and fee policy are not covered in this version. They will be published in a later version once finalised.

5. DEX

The exchange is a Uniswap V2 style automated market maker: a Factory that creates pairs, a Router that executes swaps, and pools that hold two tokens. Prices come from pool reserves. Swapping against a pool changes its price, so small pools move a lot with each trade. Adding liquidity makes prices steadier.

6. Wallet

The EfikChain Wallet is non-custodial. Keys are generated and encrypted on the user's own device and are never sent to a server. It supports creating or importing a wallet with a 12-word recovery phrase, sending and receiving EFIK, WEFIK and EUT, swapping through the Router, per-coin dashboards, and activity history. The recovery phrase is the only backup: nobody, including the project, can restore a lost one. An Android app is planned.

7. Explorer and tools

A Blockscout explorer shows blocks, transactions, addresses, tokens and verified contracts. A live price page reads the pool directly. A connect page adds the network to common wallets in one tap.

8. Security and decentralisation

Proof of authority trades some decentralisation for speed and simplicity. Today block production is run by the project team. The plan is to add independent signers on separate machines and to move control of the genesis funds to hardware wallets or a multisig. Signer keys are backed up in encrypted form. Contract code should be reviewed independently before large amounts are held in it, and no formal audit has been published yet.

9. Roadmap

  • Done: mainnet, public RPC, explorer, DEX with first pool, web wallet, price page.
  • In progress: listing in public chain registries so wallets recognise the network and logo.
  • Next: Android wallet on Google Play; more independent signers; independent code review.
  • Planned: P2P trading with escrow; fiat on and off ramps through licensed partners; a bridge to other networks; price listings once there is trading history.

10. Risks and disclaimer

EfikChain is new, experimental software. Smart contracts can contain bugs, small liquidity pools can swing sharply in price, and keys can be lost or stolen. Nothing in this document is financial, legal or tax advice, and it is not an offer to sell anything. Do your own research and use only what you can afford to lose.
